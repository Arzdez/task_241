# Перенаправляем

### 1. Как работают операторы > и >>?

`>` — перенаправляет вывод в файл. Если файл существует, его содержимое **перезаписывается**.
`>>` — перенаправляет вывод в файл, но **дописывает** в конец, не удаляя старое содержимое.

### 2. Что такое стандартные потоки stdin, stdout, stderr?

`stdin` — стандартный ввод (данные, которые программа получает, обычно с клавиатуры).
`stdout` — стандартный вывод (обычный результат работы команды).
`stderr` — стандартный вывод ошибок (сообщения об ошибках, идут отдельно от обычного вывода).

### 3. Вывести содержимое файла, не используя текстовые редакторы.
```shell
cat lab2/test.txt
```

### 4. Создать файл с содержимым, не используя текстовый редактор.
```shell
echo "первая строка" > lab2/test.txt
echo "вторая строка" >> lab2/test.txt
```

### 5.1) Перенаправить только stdout в файл.
```shell
ls lab2 > lab2/stdout.txt
```

### 5.2) Перенаправить только stderr в файл.
```shell
ls lab2/несуществующая_папка 2> lab2/stderr.txt
```

### 5.3) Перенаправить stdout и stderr в один файл.
```shell
ls lab2/несуществующая_папка lab2 > lab2/both.txt 2>&1
```

### 5.4) Перенаправить stdout и stderr в разные файлы.
```shell
ls lab2/несуществующая_папка lab2 > lab2/out.txt 2> lab2/err.txt
```

### 6. Чем отличаются stdout и stderr?

`stdout` — это обычный вывод команды (результат её работы), поток с номером 1.
`stderr` — это поток ошибок, поток с номером 2. Они разделены, чтобы можно было, например, сохранить результат в файл, а ошибки всё равно видеть на экране (или наоборот).

### 7. Что такое stdin? Пример передачи данных команде через стандартный ввод.

`stdin` — стандартный ввод (поток с номером 0). Данные можно передать команде через оператор `<` или через конвейер `|`.
```shell
sort < lab2/test.txt
cat lab2/test.txt | sort
```

### 8. Как отправить весь ненужный вывод команды в /dev/null?
```shell
ls lab2/несуществующая_папка > /dev/null 2>&1
```

### 9. Чем отличается конвейер | от перенаправления >?

`>` — перенаправляет вывод в **файл**.
`|` — передаёт вывод одной команды **на вход другой команды**, без промежуточного файла.

### 10. Собрать команду из двух или трёх программ через |.
```shell
cat lab2/test.txt | sort | uniq
```


### Краткое описание stdin, stdout, stderr и файловых дескрипторов

Каждой программе при запуске автоматически открываются три стандартных потока:

- **stdin** (дескриптор **0**) — стандартный ввод. Отсюда программа читает данные. По умолчанию — клавиатура.
- **stdout** (дескриптор **1**) — стандартный вывод. Сюда программа пишет обычный результат. По умолчанию — экран.
- **stderr** (дескриптор **2**) — стандартный вывод ошибок. Сюда пишутся сообщения об ошибках. Тоже по умолчанию идёт на экран, но отдельным потоком, чтобы его можно было перенаправить независимо от stdout.

Цифры 0, 1, 2 — это номера файловых дескрипторов. Именно их используют в командах перенаправления: `1>` — перенаправить stdout, `2>` — перенаправить stderr, `2>&1` — направить stderr туда же, куда сейчас направлен stdout.
