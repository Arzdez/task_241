# Работа в консоли

### 1. Переместиться между директориями.

```shell
pwd
cd ..
cd ~
```

### 2. Вывести список файлов в директории.

```shell
ls
```

### 3. Вывести список всех файлов, включая скрытые.

```shell
ls -la
```

### 4. Создать папку с несколькими уровнями подпапок.

```shell
mkdir -p lab1/level1/level2
```

### 5. Внутри папки создать файл и записать в него несколько строк текста.

```shell
printf "apple\nbanana\ncherry\n" > lab1/level1/level2/fruits.txt
```

### 6. Переместить файл из одной директории в другую.

```shell
mkdir -p lab1/moved
mv lab1/level1/level2/fruits.txt lab1/moved/
```

### 7. Скопировать файл из одной директории в другую.

```shell
mkdir -p lab1/copied
cp lab1/moved/fruits.txt lab1/copied/fruits_copy.txt
```

### 8. Переименовать файл.

```shell
mv lab1/copied/fruits_copy.txt lab1/copied/fruits_renamed.txt
```

### 9. Сравнить содержимое двух файлов.

```shell
diff lab1/moved/fruits.txt lab1/copied/fruits_renamed.txt
```

### 10. Отсортировать содержимое файла по возрастанию и убыванию.

```shell
sort lab1/moved/fruits.txt
sort -r lab1/moved/fruits.txt
```

### 11. Найти созданный файл по имени, не переходя вручную по всей структуре каталогов.

```shell
find lab1 -name "fruits_renamed.txt"
```

### 12. Удалить созданные в ходе задания файлы и каталоги.

```shell
rm -rf lab1
ls lab1
```


### Разница между абсолютным и относительным путём

Абсолютный путь — это полный адрес файла от самого корня системы, всегда начинается со слэша `/`. Не важно, в какой папке мы сейчас находимся, он всегда укажет на один и тот же файл. Например: `/home/anna/lab1/moved/fruits.txt`

Относительный путь — указывается от той папки, в которой мы сейчас находимся. Он не начинается со слэша. Если перейти в другую папку, тот же путь уже не сработает. Например: просто `lab1/moved/fruits.txt` — сработает только если мы в домашней папке.
